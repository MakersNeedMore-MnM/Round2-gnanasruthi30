Install CyberTwin

Free installation for testing and demonstration.

  1. Click 📦 Download CyberTwin above and download the ZIP file.
  2. Extract the downloaded CyberTwin-v1.0.0.zip file.
  3. Open Chrome and enter chrome://extensions in the address bar.
  4. Enable Developer Mode in the top-right corner.
  5. Click Load unpacked.
  6. Select the extracted CyberTwin extension folder containing manifest.json.
  7. Open the Test Playground and click the test links.
